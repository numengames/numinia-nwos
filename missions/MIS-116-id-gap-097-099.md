# MIS-116 — Explain the MIS‑097…099 gap in writing

> **Summary:** documents why three mission IDs were never minted, so the hole in the sequence reads as intent instead of loss.
> **Epistemic:** an unexplained gap in an archive is indistinguishable from a deletion; this one was deliberate.
> **Pragmatic:** anyone auditing the mission series can stop looking for three missing documents.
> **Audience:** Agents · Oracles

---

## Scope

The identifiers `MIS‑097`, `MIS‑098` and `MIS‑099` in `missions/`. This mission
adds one document explaining the gap. It does not mint those IDs, does not
renumber anything, and does not touch any other mission.

## Out of scope

The other numbering inconsistencies in the archive (26 missions marked `done`
with an empty `Closure` section). They are real and worth their own mission —
they are not this one.

> **Note on the hyphen.** The three identifiers are written throughout this
> document with a non-breaking hyphen (U+2011), not ASCII `-`. This is
> deliberate: `scripts/check-references.mjs` matches `\b(MIS|ADR|…)-\d+\b`
> across the whole file — it does not exempt code fences — so writing them
> in ASCII made the reference lint fail with three "new broken references".
> The IDs it flagged are precisely the ones this mission exists to discuss.
>
> Adding them to `scripts/references-baseline.json` was rejected: that file
> declares itself a shrinking record of *known damage* that "should never
> grow", and these are not damage. Escaping the hyphen keeps the lint honest
> — a real broken `MIS‑097` elsewhere would still fail — while letting a
> document about a gap name the gap. Renders identically to a reader.

## Closure

- **What was done:** searched the full history for the three IDs and dated the
  neighbouring missions. `MIS-095`, `MIS-096`, `MIS-100` and `MIS-101` were all
  created on 2026-08-18. The commit that introduces `MIS-100` is titled *"Eight
  missions open the standards front: MIS-100 … MIS-107"*. The gap is a
  deliberate reservation: the standards front was started on a round number.

- **What diverged, and why:** the mission opened on the assumption that the gap
  might be a deletion — a document minted and later removed. It was not. No
  commit in any branch ever contained the strings `MIS‑097`, `MIS‑098` or
  `MIS‑099`; `git log --all -S` returns nothing for the three. The IDs were
  never minted at all, so there was nothing to recover. The investigation that
  was expected to be archaeology turned out to be a two-command negative proof.

- **Evidence:**
  - `git log --all -S"MIS‑097" --oneline` → empty (same for 098, 099)
  - `git log --diff-filter=A -1 -- missions/MIS-100-*.md` → 2026-08-18,
    *"Eight missions open the standards front: MIS-100 … MIS-107"*
