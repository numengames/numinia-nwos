### `ADR-023` — four terms, two pairs, and a triad that was never in conflict

The longest thread of the day, and the diagnosis in `D-012` was wrong.

`D-012` said the canon contradicted itself: an unfinished substitution. The
version deleted on 2026-04-15 — **recovered today from git and filed as
evidence** — shows otherwise:

| | v1 (deleted) | v2 (live) |
|---|---:|---:|
| `operating system` | 7 | **5** |
| `Functional Model` | **8** | 0 |
| `Germinal Motive` | 0 | **8** |

**v2 keeps `operating system` while introducing `Germinal Motive`.** It was not
renaming a concept; it was splitting one phrase into two. What failed was the
2026-05-06 edit to `C-001-welcome-to-numinia.md`, which applied a correct distinction
to a line whose sense was operative.

The Oracle's rule:

```
Is there something INSIDE it?       → operating system
Is it the ORIGIN?                   → germinal motive
Does it describe WHAT IT DOES?      → Functional Model
Does it describe WHAT VALIDATES?    → Regulatory Model
```

And the last cabo was closed by the corpus, not by either option on the table.
`Pragmatic_Numen_System` §2.3: *"Function and structure are distinguishable
planes, but not separable."* **`Functional` and `Regulatory` are two planes of
one level** — so `Welcome` line 45 was never a leftover.

One line corrected in canon (line 42), authorised by the ADR and ordered by the
Oracle. Nothing else.

## Three rulings that changed how the glossary reads

**§2.1.1 — git history is the fifth threshold, and the only real one.** The four
thresholds `S-001` defines are social conventions; git's is imposed by the tool.

> When the two disagree, the history is the record and the document is the
> claim.

**§2.1.2 — `live`, the threshold for state rather than record.** A memory
asserts something about the present, so correcting it falsifies nothing — but it
corrects an actor in motion, and the correction is recorded **inside the memory**
so the agent can see it was corrected and by whom.

> A memory silently rewritten produces an actor that changed its mind without
> knowing it did.

**§5.2 — an agent that has committed never loses its name.** Git authorship
cannot be rewritten; a rename adds a name, it never replaces one.

### Three rulings added to `S-001`

**§10.0.1 — failure by omission.** *A failure by omission produces no error; it
produces a valid artefact that is smaller than it should be.* With the corollary
the Oracle called the actionable part:

> **A guard that validates what is present cannot detect what is missing.**
> All three instances were found by an *independent enumeration* — the
> filesystem against the index, the glob against the folder list, the renames
> against the redirect table — and none by the tool that owned the artefact.

**§3.1 — enumeration is apparatus, relation and judgement are record.** Four
indexes contain nothing a machine could not derive; `canon/INDEX.md` carries 7
relations, 6 scores and 8 explanations that exist in no file. An `INDEX.md` is
both natures at once, which is why nobody could place it.

**§5.3 — a rename propagates to pointers, never to records.** Caught mid-edit: a
script had rewritten four dated reports so an April inventory claimed a filename
that did not exist in April.
